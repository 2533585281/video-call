让手机连上她

请用 Chrome 或 Safari 打开。微信、QQ、抖音里的浏览器装不了证书，也经常不给麦克风。

人在家里

先装下面这张证书，再用带锁的地址打开。普通的 http 网址，手机不给麦克风，也不给摄像头。

通话地址：https://192.168.1.23:12394/

安卓下载证书 iPhone 下载描述文件

安卓

  1. 点「安卓下载证书」。如果提示可能有害，选仍要下载。文件名如果变成了别的，改成 ca.crt。
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书。要装进「用户凭据」，不要装成 VPN。
  3. 关掉 Chrome 再打开，用上面的 https 地址。第一次允许麦克风和摄像头。

iPhone

  1. 点「iPhone 下载描述文件」，允许下载。
  2. 设置 → 通用 → VPN 与设备管理 → 安装描述文件。
  3. 设置 → 通用 → 关于本机 → 证书信任设置 → 打开这张证书的开关。不打开的话，Safari 仍然不给麦克风。
  4. 用 Safari 打开上面的 https 地址。

人在外面

家里这张自签证书到了外网就对不上地址。外面用 Tunnel 给的那条 https 链接，手机什么都不用装。同样不要放进微信里打开。

让她看见你

页面左上角设置 → 通用 → 打开「使用摄像头背景」。这一步只有 https（或电脑上的 127.0.0.1）才做得到。开着摄像头说话时，这一帧会跟着话一起发给她。
